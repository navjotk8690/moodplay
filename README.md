# MoodPlay

MoodPlay transforms your emotions into calming browser-based mini-games designed to help you pause, relax, and reconnect.

## Features

- Analyses free-text emotional input
- Uses a local Hugging Face Transformers model
- Generates a mini-game based on the detected mood
- Includes multiple interactive games
- Responsive desktop and mobile design
- No external AI API key required

## Technology

- Python
- FastAPI
- Hugging Face Transformers
- PyTorch
- HTML
- CSS
- JavaScript
